## 1. Command-line binaries

All `[[bin]]` found in Cargo.toml files plus `src/main.rs` / `src/bin/*.rs`. Fuzz targets (fuzz*, verifier/fuzz, audit/fuzz) are cargo-fuzz targets, not user tools.

The three database CLIs (`sever-db`, `sever-db-p3`, `sever-db-p2`) share one hand-written parser: first argument is the command, then `--name value` pairs; a `--name` followed by another `--` or nothing is a bare flag with empty value [CODE: crates/sever-db/src/bin/sever-db.rs:37-65]. Every command opens the database (recovery + invariant check), does one thing, prints ONE JSON line, closes [CODE: sever-db.rs:1-4]. Exit code: 0 ok, 1 = `{"error":"<kind>"}` (a typed error), 2 = usage error on stderr [CODE: sever-db.rs:299-315].
